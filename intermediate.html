模組一：甚麼是 Brisk 和如何用 Brisk

專為教育工作者設計的 Chrome 擴充功能，直接在 Google Docs 中發揮 AI 威力。

甚麼是 Brisk Teaching？

Brisk Teaching 是一個免費的 Google Chrome 擴充功能，它能無縫整合到您常用的工具中（如 Google Docs、Classroom、網頁文章）。它不需要您打開新的 AI 聊天視窗，而是直接在您正在閱讀或編輯的頁面上提供 AI 輔助。

給予學生回饋

在 Google Docs 批改學生文章時，Brisk 能根據您設定的評分準則 (Rubrics) 自動生成具建設性的回饋意見。

調整閱讀難度

看到一篇適合教學但太難的網頁文章？點擊 Brisk，一鍵將文章改寫為適合小學或初中程度的閱讀材料。

生成教學資源

從任何文章或 YouTube 影片，快速生成教案、測驗卷、工作紙，並直接匯出為 Google Docs 或 Forms。

如何使用 Brisk

  1. 1 安裝擴充功能： 前往 Chrome Web Store 搜尋「Brisk Teaching」並新增至 Chrome。
  2. 2 開啟網頁或文件： 打開一篇您想用作教材的網頁文章，或打開學生的 Google Doc 功課。
  3. 3 點擊 Brisk 圖示： 在畫面右下角會出現 Brisk 的羽毛圖示，點擊它展開選單。
  4. 4 選擇功能： 選擇「Change Level (改變難度)」、「Create (建立資源)」或「Give Feedback (給予回饋)」，AI 就會立即在您的畫面上開始工作！

模組二：甚麼是 Diffit 和如何用 Diffit

為不同程度的學生提供「剛剛好」的學習材料，實現差異化教學。

甚麼是 Diffit？

Diffit 是一個專為「差異化教學 (Differentiated Instruction)」打造的 AI 平台。它可以將任何主題、網址、PDF 或文字，瞬間轉化為適合不同閱讀程度的教材，並自動生成配套的詞彙表、選擇題和簡答題。

核心功能

  • 調整閱讀程度： 將同一篇文章改寫為適合小二到中六的不同難度。
  • 多語言翻譯： 支援將教材翻譯成超過 50 種語言，適合非華語學生 (NCS)。
  • 自動生成練習： 根據文章內容，自動產生重點摘要、詞彙表、MC 題及開放式問題。

豐富的匯出選項

生成的教材可以直接匯出為多種格式，完美融入您的教學流程：

Google Docs Google Forms Google Slides PDF / Word

如何使用 Diffit

Step 1: 輸入來源

前往 web.diffit.me。您可以選擇輸入一個主題（如：香港歷史）、貼上一段網址，或者上傳一份 PDF 文件。

Step 2: 設定程度

選擇您目標學生的閱讀程度（例如：4th Grade）以及輸出的語言（例如：繁體中文）。

Step 3: 生成與匯出

點擊 Generate。檢查 AI 生成的文章與題目，確認無誤後，點擊右上角的 Export 匯出至 Google Classroom。

模組三：GEM 生成 Google Forms MC

進階自動化：上傳教材至 Gemini，讓 AI 寫出 Apps Script 自動建立 20 題 Google Form 測驗。

1 設定 GEM (系統指令)

在 Gemini 中建立一個新的 Gem，並貼上以下 System Instructions：

gem_instructions.txt 
你是一位精通教育評估與 Google Apps Script (GAS) 的專家。你的任務是根據我提供的教材，設計高質素的多項選擇題 (MC)，並編寫能直接在 Google Forms 執行的 Apps Script 程式碼。

要求：
1. 選擇題必須有 4 個選項 (A, B, C, D)。
2. 題目需具備挑戰性，避免過於直接的抄寫題。
3. 輸出的 Apps Script 必須設定好正確答案及每題的分數。

2 上傳教材與輸入 Prompt

將您的教材 (PDF/Word) 上傳至對話框，然後輸入以下 Prompt：

gas_prompt.txt 
請根據我上傳的教材，幫我設計 20 題中三級程度的 MC 題。

然後，請提供一段完整的 Google Apps Script 程式碼，讓我可以在執行後，自動建立一個名為「單元測驗」的 Google Form，並將這 20 題 MC 題（連同正確答案設定及每題 1 分）自動匯入該問卷中。請確保程式碼可以直接複製執行。

3 執行 Apps Script 建立問卷

  1. 在瀏覽器網址列輸入 script.new，這會自動開啟一個新的 Google Apps Script 專案。
  2. 將編輯器中原有的 function myFunction() {} 刪除。
  3. 將 Gemini 生成的程式碼貼上到編輯器中。
  4. 點擊上方的 「儲存」 圖示（或按 Ctrl+S）。
  5. 點擊上方的 「執行 (Run)」 按鈕。
  6. 首次執行時，Google 會要求授權。點擊「審查權限」 > 選擇您的帳號 > 點擊「進階」 > 點擊「前往專案 (不安全)」 > 點擊「允許」。
  7. 執行完成後，前往您的 Google Drive，您就會看到一份已經設定好 20 題 MC 及正確答案的 Google Form！

模組四：教學應用 GEM - 生成互動教材 Web App

教老師上傳教材、輸入 Prompt，讓 Gemini 產生可直接開啟的 single HTML 互動教材。

甚麼是「教學應用 GEM」？

教學應用 GEM 是一個專為老師設定的 Gemini 自訂助手。老師只需要上傳教材（例如 PDF、Word、簡報或課文），再輸入清晰的教學目標，GEM 就可以把教材轉化成一個單頁 HTML Web Application，例如互動筆記、概念檢查、配對活動、翻卡、即時小測、答案顯示與反思題。

上傳教材

把課文、簡報、工作紙或筆記上傳至 Gemini，讓 AI 先讀懂內容、重點與難度。

輸入教學 Prompt

指定年級、學習目標、活動形式、互動元素、語言及輸出格式。

生成 single HTML

取得一個完整 HTML 檔案，老師可直接儲存為 lesson.html，或上載到 GitHub Pages。

1 建立 GEM：系統指令範本

在 Gemini 建立新 Gem，名稱可設定為「互動教材 Web App 設計師」，然後貼上以下指令：

interactive_webapp_gem.txt 
你是一位專業的教育科技設計師、課程設計專家及前端網頁開發者。你的任務是根據老師上傳的教材，設計一個可直接在瀏覽器開啟的 single HTML interactive web application，幫助學生自主學習及互動練習。

請嚴格遵守以下要求：
1. 先閱讀並整理教材重點，再轉化成清晰的教學流程。
2. 產出的網頁必須是單一 HTML 檔案，包含 HTML、CSS、JavaScript，不依賴額外本地檔案。
3. 可使用 CDN，例如 Tailwind CSS、Font Awesome，但不可要求老師安裝任何工具。
4. 網頁必須包含互動元素，例如翻卡、配對題、MC 題、即時回饋、答案顯示、進度追蹤或反思題。
5. 設計要專業、色彩生動、適合課堂展示及學生自學。
6. 必須使用繁體中文，除非老師另有要求。
7. 如果教材屬語文科、英文科或包含大量新詞，必須加入 vocab list，包括詞語、詞性、中文解釋、英文解釋、例句及學生友善解釋。
8. 如果教材屬英文或語文學習，必須加入語音功能，例如 Listen / Read Aloud 按鈕，使用瀏覽器 Web Speech API 的 speechSynthesis 朗讀文章、例句或 vocabulary。不要要求老師另外上傳音訊檔。
9. 語音功能需要有清晰按鈕、播放狀態提示及停止朗讀按鈕；英文教材優先使用 en-US 或 en-GB voice，中文教材優先使用 zh-HK 或 zh-TW voice。
10. 若教材資訊不足，請先提出 3 個澄清問題；若足夠，直接輸出完整 HTML 程式碼。

2 上傳教材後：任務 Prompt 範本

老師上傳教材後，可直接複製以下 Prompt，按需要修改年級及主題：

webapp_task_prompt.txt 
請根據我上傳的教材，製作一個適合 [請填寫年級] 學生使用的 single HTML interactive web application。

主題：[請填寫課題]
學習目標：
1. [目標一]
2. [目標二]
3. [目標三]

請包含以下部分：
- 課前導入：用簡短故事或問題引起興趣
- 重點教學：用卡片或時間線整理教材重點
- 互動練習：至少 5 題 MC 題，學生作答後即時顯示回饋
- 鞏固活動：配對題、排序題或翻卡活動
- 總結反思：提供 2 條開放式反思問題

如果這份教材是語文科或英文教材，請額外加入：
- Vocabulary List：至少 12 個重點字詞，包含詞性、中文解釋、英文解釋及例句
- Listen 按鈕：可朗讀課文重點、例句及 vocabulary
- Pronunciation Practice：學生可逐個字詞按發音，並看到簡單發音提示
- Reading Aloud Practice：提供一段短文，讓學生跟讀
- 所有語音請使用 JavaScript Web Speech API (speechSynthesis)，不要使用外部音訊檔

技術要求：
- 請輸出完整 HTML 程式碼
- 所有 CSS 和 JavaScript 必須放在同一個 HTML 檔案內
- 版面要專業、色彩生動、手機和電腦都能使用
- 不要只給片段，不要省略任何程式碼

3 語文科及英文教材：必加功能

Vocabulary List

GEM 需要從教材抽取重點詞彙，並整理成學生可自學的詞彙表。

  • 詞語 / 詞性 / 中文解釋 / 英文解釋
  • 每個字詞配一個例句
  • 可加入翻卡或配對練習

語音朗讀與發音練習

GEM 需要使用瀏覽器內置的 Web Speech API 製作 Listen 按鈕，不需要上傳 MP3。

  • 朗讀課文重點、例句和 vocab
  • 提供 Stop 按鈕停止朗讀
  • 英文使用 en-US / en-GB，中文使用 zh-HK / zh-TW

4 老師實作流程

  1. 準備教材，例如 PDF、Word、Google Docs 文字、PowerPoint 講義或課文截圖。
  2. 打開 Gemini，進入剛建立的「互動教材 Web App 設計師」Gem。
  3. 上傳教材，然後貼上「任務 Prompt 範本」。
  4. 檢查 Gemini 輸出的 HTML 程式碼，要求它修正任何錯誤或補充更多互動元素。
  5. 把完整程式碼複製到記事本或 VS Code，儲存為 lesson.html。
  6. 雙擊 lesson.html 即可在瀏覽器開啟，也可上載到 GitHub Pages 與學生分享。
