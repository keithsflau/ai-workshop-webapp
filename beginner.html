模組一：寫 Prompt 的基礎元素

掌握 CREATE 或 RTF 框架，讓 AI 準確理解您的需求。

一般指令 (Bad Prompt)

bad_prompt.txt 
幫我出一份小三中文測驗卷。

缺乏細節，AI 只能靠猜測來生成內容。

優質指令 (Good Prompt)

good_prompt.txt 
你現在是一位擁有20年經驗的香港小學中文科資深教師。(Role)
請幫我設計一份小學三年級下學期的中文科測驗卷。(Task)
測驗卷請以表格形式呈現，包含題目、分數、及建議答案。(Format)
測驗內容需涵蓋：
1. 重組句子 (3題)
2. 供詞充寫 (5題)
3. 閱讀理解 (1篇約200字短文，附3條選擇題及1條短答題)
學生程度為中等，題目需符合香港教育局課程指引。(Context)

角色清晰、任務具體、格式明確、背景資料充足。

RTF 框架解析

R
Role (角色)
賦予 AI 專業身份（如：資深教師），決定其語氣與專業度。
T
Task (任務)
明確指出希望 AI 完成的具體工作，越詳細越好。
F
Format (格式)
指定輸出的排版形式（如：表格、列點、Markdown）。
C
Context (背景)
提供必要的背景資訊（如：學生程度、字數限制）。

模組二：用 Prompt 去寫 Prompt

讓 AI 成為您的專屬 Prompt 工程師 (Meta-prompting)。

萬用 Prompt 生成器指令

Pro Tip

將以下指令複製到 Gemini，讓它引導您寫出完美的 Prompt。

meta_prompt.txt 
你現在是一位頂級的「AI Prompt 工程師」，專門協助教師設計最有效的 AI 指令。
我會給你一個初步的想法或任務，請你根據 CREATE 或 RTF 框架 (Role, Task, Format, Context)，幫我擴寫並優化成一個完美的 Prompt。

在給出最終的 Prompt 之前，請先問我 2-3 個關鍵問題，以釐清我的具體需求（例如：對象是誰？有什麼特殊限制？需要什麼格式？）。
當我回答後，請提供優化後的 Prompt，讓我可以直接複製使用。

我初步的想法是：[請在此填寫您的初步想法，例如：幫我寫一篇關於中秋節的早會演講稿]

模組三：製作 GEM 處理學校文件

自訂專屬 AI 助手，根據學校格式處理日常文件。

1

準備知識庫 (Knowledge Base)

請準備好以下工作坊提供的附件檔案，上傳至 Gem 的知識庫中：

  • 2526_YP_template (1).docx
  • E12A_活動或比賽申請表(new).docx
  • E13A(e)_校外活動通告(無收費)NEW.doc
  • 學生課業評估_課業設計簡介表C_KYC.doc
  • 附件1_教案表格_CL_13_10_25.docx
2

設定 Gem (System Instructions)

system_instructions.txt 
你是一位專業的香港學校行政助理及資深教師，非常熟悉香港教育局的指引及一般學校文件的格式與用語。
你的任務是協助教師處理日常學校文件，包括但不限於：活動申請表、家長通告、課業設計簡介表及教案。

請嚴格遵守以下原則：
1. 語氣：專業、得體、客觀，符合香港教育界慣用語（如使用「學生」、「家長」、「法團校董會」等）。
2. 格式：當我要求填寫特定文件時，請參考知識庫中提供的範本格式（例如 E12A, E13A(e) 等），並盡量以 Markdown 表格或清晰的列點形式輸出，方便我直接複製到 Word 文件中。
3. 準確性：若提供的資訊不足以填寫整份表格，請在缺失的部分標註 [請填寫...]，不要自行捏造虛假資料。
4. 語言：除非特別指明，否則請使用繁體中文（廣東話/書面語）。
3

測試您的 Gem

測試案例 1：活動申請表

請幫我根據知識庫中的「E12A_活動或比賽申請表」，草擬一份關於「秋季大帽山環保行山活動」的申請。對象是中四學生，日期是下個月 15 號，預計 40 人參與，需要 2 部旅遊巴。

測試案例 2：撰寫教案

參考知識庫中的「教案表格」，幫我設計一堂 40 分鐘的中二級中文課教案。課題是《背影》(朱自清)，教學重點是認識「借物抒情」的寫作手法。

模組四：撰寫家長信

使用結構化 Prompt，快速撰寫專業且得體的家長信。

場景一：課外活動通告

activity_notice.txt 
你是一位香港中學的負責老師。請幫我撰寫一封家長通告，邀請學生參加課外活動。
(Role: 香港中學老師)
(Task: 撰寫家長通告)
(Format: 正式信件格式，包含上款、正文、下款及回條)

請根據以下資料撰寫 (Context)：
- 活動名稱：[請填寫，例如：香港科學館參觀活動]
- 日期：[請填寫，例如：2026年10月15日]
- 時間：[請填寫，例如：上午9時至下午1時]
- 地點：[請填寫，例如：尖沙咀香港科學館]
- 費用：[請填寫，例如：全免 / $50]
- 交通安排：[請填寫，例如：學校旅遊巴接送]
- 截止報名日期：[請填寫，例如：2026年10月1日]

語氣需禮貌、清晰，並強調活動對學生的教育意義。

場景二：學生表現關注信

student_concern.txt 
你是一位香港小學的班主任。請幫我草擬一封致家長的信件，表達對學生近期表現的關注。
(Role: 香港小學班主任)
(Task: 撰寫學生表現關注信)
(Format: 誠懇而專業的書信格式)

請根據以下資料撰寫 (Context)：
- 學生姓名：[請填寫]
- 關注事項：[請填寫，例如：近期欠交功課情況嚴重 / 上課時欠缺專注]
- 老師已採取的行動：[請填寫，例如：已多次口頭提醒 / 已安排課後輔導]
- 期望家長配合的地方：[請填寫，例如：督促子女完成家課 / 留意子女作息時間]

語氣必須婉轉、具同理心，強調家校合作的重要性，避免使用指責的口吻。請在信末邀請家長致電學校聯絡班主任。

模組五：用 Gemini 製作教學 PowerPoint

從大綱到 VBA 程式碼，一鍵生成精美教學簡報。

方法 A：生成結構化大綱

推薦做法
ppt_outline.txt 
請幫我設計一份教學簡報的大綱。
主題：[請填寫，例如：光合作用]
對象：[請填寫，例如：中一學生]
長度：約 [請填寫，例如：10] 頁投影片

請以 Markdown 格式輸出，每一頁為一個區塊，包含：
- 投影片標題 (Slide Title)
- 內文要點 (Bullet Points)
- 視覺建議 (Visual Suggestion，例如：建議配上植物吸收陽光的圖片)
- 講者備忘 (Speaker Notes)

提示：將生成的大綱複製到 Word 中，然後在 PowerPoint 中選擇「從大綱新增投影片」(New Slide from Outline)，即可快速匯入文字。

方法 B：使用 VBA 一鍵生成

進階挑戰
ppt_vba.txt 
你是一位精通 PowerPoint VBA 的專家。請幫我寫一段 VBA 程式碼，用來自動生成一份教學簡報。

簡報主題：[請填寫，例如：人工智能在教育的應用]
對象：[請填寫，例如：中學教師]
預計頁數：約 [請填寫，例如：8-10] 頁

請確保 VBA 程式碼符合以下要求：
1. 包含標題頁及目錄頁。
2. 每頁投影片需有清晰的標題和列點形式的內文 (Bullet points)。
3. 內容需具備邏輯性，涵蓋主題的簡介、核心概念、實際應用案例及總結。
4. 程式碼必須能夠直接在 PowerPoint 的 VBA 編輯器中運行而不會報錯。
5. 請在程式碼前後加上說明，教我如何將這段 VBA 貼上並執行。
如何執行 VBA：
  1. 打開 PowerPoint，按下 Alt + F11 開啟 VBA 編輯器。
  2. 在上方選單選擇「插入 (Insert)」 > 「模組 (Module)」。
  3. 將 AI 生成的程式碼貼上到空白視窗中。
  4. 按下 F5 或點擊上方的「執行 (Run)」按鈕。
