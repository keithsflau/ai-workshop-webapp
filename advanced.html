模組一：Cursor 是甚麼，教師可以點樣用

Cursor 不只是寫程式工具，也可以成為老師的文件、教材和校務工作台。

教師版理解

Cursor 是一個內置 AI Agent 的編輯器。老師可以把教材、活動文件、表格、HTML 網頁或 Markdown 筆記放入資料夾，然後要求 Cursor 讀取、整理、改寫、生成互動教材，甚至協助上傳到 GitHub Pages。即使不懂編程，也可以把它當成「校務文件及教材製作助理」。

文件草擬

活動申請、家長信、教案、會議紀錄、通告初稿。

教材設計

工作紙、互動網頁、vocab list、小測、配對活動。

資料整理

問卷結果、報名名單、學生分組、統計摘要。

網站發佈

把 single HTML 教材上載到 GitHub Pages 分享。

模組二：用 Cursor 處理學校行政文件

把零散資料轉成可交付文件，減少重複輸入和格式錯誤。

1. 收集範本

把活動申請表、校外活動通告、教案表、評估表放入同一資料夾。

2. 提供活動資料

用文字列出活動名稱、日期、地點、學生對象、費用、老師安排。

3. 產生文件草稿

要求 Cursor 對照範本，輸出通告、申請表內容及填寫 checklist。

school_admin_prompt.txt 
請閱讀這個資料夾內的學校文件範本，幫我整理每份文件的用途、必填欄位、語氣和格式要求。

然後根據以下活動資料，生成：
1. 家長通告草稿
2. 活動申請表內容
3. 需要老師補充資料的 checklist

活動資料：
- 活動名稱：[填寫]
- 日期及時間：[填寫]
- 地點：[填寫]
- 對象：[填寫]
- 費用：[填寫]
- 帶隊老師：[填寫]

要求：繁體中文、香港學校語氣、不要捏造未知資料，缺失位置用 [請補充] 標示。

模組三：用 Cursor 製作教材 Web App

把教材轉成 single HTML interactive lesson，加入小測、翻卡、語音與 vocab list。

建議工作流

老師可把課文、PDF 摘要或教學重點整理成文字檔，交給 Cursor 製作一頁式互動教材。完成後可要求 Cursor 修改色彩、加入語音朗讀、加入 vocabulary cards，再推送到 GitHub Pages。

interactive_lesson_prompt.txt 
請根據我提供的教材內容，製作一個 single HTML interactive web application。

要求：
1. 適合 [年級] 學生
2. 包含課前導入、重點教學、互動練習、總結反思
3. 至少 8 題 MC 題，學生作答後即時顯示回饋
4. 加入翻卡或配對活動
5. 如果是英文或語文教材，加入 vocab list、例句和 Listen 按鈕
6. 所有 HTML、CSS、JavaScript 必須放在同一個檔案
7. 主題要專業、色彩生動、手機和電腦都可用

完成後請把檔案命名為 lesson.html，並說明如何上載到 GitHub Pages。

模組四：校本資料整理與批量工作

用 Cursor 整理問卷、名單和報名資料，但必須注意學生私隱。

私隱提醒

處理學生資料前，應先移除姓名、電話、身份證、住址、家長聯絡等個人資料。可改用學生編號、班別代號或匿名 ID，再讓 AI 協助整理與分析。

課前問卷分析

把 CSV 匯出結果交給 Cursor，整理老師最想學的 AI 工具、信心程度和培訓需要。

學生分組

按興趣、程度、選修科或需要支援程度，生成分組建議和跟進策略。

批量訊息草稿

根據不同情況生成 email、WhatsApp 或家長通知短訊草稿。

活動名單核對

檢查重複報名、欠交資料、未付款、特殊飲食或交通安排。

data_cleanup_prompt.txt 
請先檢查這份資料是否包含個人敏感資料，並列出需要匿名化的欄位。

然後在不透露個人身份的前提下，幫我：
1. 總結主要趨勢
2. 找出需要跟進的群組
3. 生成 5 個行動建議
4. 產出可貼入簡報的摘要段落

資料用途：[例如：教師工作坊課前調查 / 活動報名 / 學生支援需要]

模組五：Cursor Agent 工作流與安全守則

用清晰流程管理大型任務，保持版本、審核與私隱安全。

Plan
先要求 Cursor 出計劃
Implement
只改指定檔案
Preview
本機檢查效果
Commit
保存版本紀錄
Publish
上傳 GitHub Pages
cursor_agent_workflow.txt 
請先不要修改檔案。請你先閱讀相關檔案，為這個學校任務制定一個清晰計劃。

任務：[描述要處理的校務或教材工作]
限制：
- 只可以修改 [指定檔案]
- 保留原有風格
- 不要刪除現有內容，除非先解釋原因
- 完成後請檢查錯誤，並列出我需要人工審核的位置

我確認計劃後，才開始實作。

學校使用守則

  • AI 內容必須由老師審核，尤其是事實、評分、家長信語氣。
  • 不把學生敏感資料直接放入公開 AI 工具；先匿名化或概括化。
  • 保留版本紀錄，重要文件先複製副本再修改。
  • 對外發佈前檢查版權、圖片來源、學生資料和學校政策。
